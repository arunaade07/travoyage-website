# 🌍 Travoyage - Travel Landing Page

Travoyage is a modern, responsive travel agency landing page built with HTML and CSS. It features a clean, user-friendly interface designed to showcase travel destinations, services, and customer experiences while demonstrating responsive web design principles.

## ✨ Features

- Responsive navigation bar
- Smooth scrolling navigation
- Hero section with call-to-action buttons
- Services section
- Destination showcase
- Why Choose Us section
- Customer testimonials
- Travel gallery
- Newsletter subscription form
- Footer with contact information and social media links
- CSS hover effects and animations
- Fully responsive layout using Flexbox and media queries

## 🛠️ Technologies Used

- HTML5
- CSS3
- Font Awesome

## 📱 Responsive Design

The website is fully responsive and adapts to desktops, tablets, and mobile devices using CSS Flexbox and media queries.
